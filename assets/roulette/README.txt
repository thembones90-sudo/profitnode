PROFITNODE THE ROULETTE - PRODUCTION ART V11

This pack contains seven individually generated production assets.

Canonical files:
- judgement_core_chassis.png  1024x1024 transparent
- wager_core_chassis.png      1024x1024 transparent
- roulette_hub.png             512x512 transparent
- roulette_pointer.png         256x512 transparent
- roulette_crest.png           512x512 transparent
- roulette_background_overlay.png 1920x1080 transparent
- roulette_result_altar.png   1920x512 transparent

Important integration doctrine:
- Live roulette sectors, text, labels, buttons and state remain HTML/CSS/JS.
- Chassis assets sit BEHIND/AROUND the live wheel, never over the labels.
- Hub contains no live PN/R text. Render PN/R in HTML above it.
- Pointer remains fixed while wheel rotates underneath.
- Background overlay is decorative and should be used at low opacity.
- Result altar is only a frame; live result text remains HTML.

The _SOURCE_GENERATIONS folder preserves the untouched generated originals.
